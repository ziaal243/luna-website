# Ziad Alghazi – personlig konsultwebbplats

Källkod till lunaitconsulting.se.

## Filer
- index.html: sidans innehåll och CSS.
- assets/logo.png: logotyp.

## Användning
Öppna index.html i en webbläsare. Ingen byggprocess eller installation behövs.
Typsnitten hämtas från Google Fonts; lokala reservtypsnitt används vid behov.

## Publicering
Webbplatsen är publicerad via Sites. Denna kopia kan lagras på GitHub eller publiceras på ett valfritt webbhotell för statiska sidor.
Ändringar på GitHub uppdaterar inte automatiskt den nuvarande publiceringen på Sites.

Denna export innehåller inga kontonycklar, CV-filer eller interna inställningar för Sites.
